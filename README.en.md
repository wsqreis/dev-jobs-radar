# Dev Jobs Radar

Dev Jobs Radar is an open-source project designed to show how SerpApi can power a useful job discovery experience for Brazilian and Portuguese-speaking developers.

## Goal

This project combines:

- practical integration with SerpApi's Google Jobs API
- a Next.js + TypeScript web interface
- a CLI that reuses the same integration layer
- bilingual documentation ready for portfolio and technical content

## Current status

The first milestone establishes the repository foundation. The next steps will add the live API integration, dashboard, CLI, tests, and complete documentation.

## Initial structure

```text
src/app             Next.js application
src/components      interface components
src/lib             integrations and domain logic
docs                architecture and walkthrough docs
scripts             project CLI
src/tests           tests and fixtures
```
