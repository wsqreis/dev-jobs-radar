# Dev Jobs Radar

Dev Jobs Radar é um projeto open-source criado para demonstrar como a SerpApi pode ser usada para construir uma experiência útil de descoberta de vagas para desenvolvedores do mercado brasileiro e lusófono.

## Objetivo

O projeto combina:

- integração prática com a Google Jobs API da SerpApi
- uma interface web em Next.js + TypeScript
- uma CLI reutilizando a mesma camada de integração
- documentação bilíngue pronta para portfólio e conteúdo técnico

## Status atual

A primeira milestone prepara a base do repositório. As próximas entregas vão incluir integração real com a API, dashboard, CLI, testes e documentação completa.

## Estrutura inicial

```text
src/app             aplicação Next.js
src/components      componentes da interface
src/lib             integrações e lógica de domínio
docs                documentação de arquitetura e walkthrough
scripts             CLI do projeto
src/tests           testes e fixtures
```
